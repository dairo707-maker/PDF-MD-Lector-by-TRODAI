# Code Signing ($0 Free Strategy) & Windows 11 Installation Guide

## 1. Distribution Artifacts

| Artifact | Purpose | Elevation Required |
|---|---|---|
| `PDF-MD-Lector-Portable.exe` | Single-file portable Windows 11 executable (`--onefile --noconsole/--windowed`, zero `QtWebEngine*`). | None |
| `PDF-MD-Lector-Setup.exe` | Inno Setup 6 multilingual wizard (`ES` / `EN` / `PT-BR` / `PT`) with optional `HKCU` file associations and clean uninstall. | None (`PrivilegesRequired=lowest`, optional dialog override) |
| `SHA256SUMS.txt` | Deterministic SHA-256 manifest (`<64-hex>  <filename>`) for every release binary. | N/A |

## 2. Building Locally

```powershell
uv sync --extra dev --link-mode=copy
uv run --no-sync python scripts/build_exe.py
```

`scripts/build_exe.py`:
1. Reads `VERSION` (`0.1.0`) and uses `assets/icons/pdf_lector.ico`.
2. Generates `0px` TRODAI Obsidian Navy wizard BMPs (`assets/icons/wizard_large.bmp`, `wizard_small.bmp`) for Inno Setup 6.
3. Builds `dist/PDF-MD-Lector-Portable.exe` via PyInstaller (`--noconsole --windowed`), bundling `VERSION`, `assets/fonts`, `assets/icons`, and `browser-extension` (if present), while excluding unused `QtWebEngine*`, `QtPdf*`, `Qt3D*`, `QtQuick`, and `QtQml` modules.
4. Compiles `dist/PDF-MD-Lector-Setup.exe` when Inno Setup 6 (`ISCC.exe`) is installed.
5. Calls optional signing hooks (`PDF_LECTOR_SIGN_PFX` / `PDF_LECTOR_SIGN_SHA1` / `PDF_LECTOR_SIGN_LOCAL=1`).
6. Generates deterministic `dist/SHA256SUMS.txt`.

## 3. $0 Local Authenticode Signing (`scripts/sign_local.ps1`)

No Windows SDK (`signtool.exe`) or paid certificate is required. `scripts/sign_local.ps1` uses native PowerShell PKI cmdlets (`New-SelfSignedCertificate` + `Set-AuthenticodeSignature`) with subject `CN=TRODAI Local Code Signing (PDF/MD Lector)`:

```powershell
# Safe preview (NEVER modifies Cert:\CurrentUser\Root or My)
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/sign_local.ps1 -DryRun

# Create/reuse local per-user CodeSigning cert and sign dist\*.exe
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/sign_local.ps1

# Optional: trust your own local public certificate in CurrentUser\Root (explicit user action only)
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/sign_local.ps1 -InstallTrust

# Remove the local certificate from CurrentUser\Root and CurrentUser\My
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/sign_local.ps1 -UninstallTrust
```

Note: Self-signed local certificates validate integrity on the machine (or organization) that explicitly chose `-InstallTrust`, and are never installed silently during builds or tests.

## 4. Verifying Release Checksums & SLSA Provenance ($0 Supply Chain Trust)

### Verify `SHA256SUMS.txt` in PowerShell

```powershell
Get-FileHash .\PDF-MD-Lector-Portable.exe -Algorithm SHA256
Get-FileHash .\PDF-MD-Lector-Setup.exe -Algorithm SHA256
Get-Content .\SHA256SUMS.txt
```

### Verify GitHub SLSA Build Provenance

Official GitHub Releases generated by `.github/workflows/build-release.yml` attach cryptographic build provenance via `actions/attest-build-provenance@v2`:

```powershell
gh attestation verify .\PDF-MD-Lector-Portable.exe --owner dairo707-maker
gh attestation verify .\PDF-MD-Lector-Setup.exe --owner dairo707-maker
```

## 5. Free Public OSS Code Signing via SignPath.io

For public Windows SmartScreen-trusted Authenticode signatures at `$0`, `.github/workflows/build-release.yml` includes a documented `signpath-oss` job template:

1. Register `github.com/dairo707-maker/PDF-MD-Lector-by-TRODAI` with the **SignPath.io Free Open Source** program (requires MIT license and reproducible GitHub Actions builds).
2. Add `SIGNPATH_API_TOKEN`, `SIGNPATH_ORGANIZATION_ID`, and `SIGNPATH_PROJECT_SLUG` to GitHub Repository Secrets.
3. Uncomment the `signpath-oss` job in `.github/workflows/build-release.yml`.

## 6. Inno Setup 6 Per-User Installer (`packaging/installer.iss`)

- `AppId=TRODAI.PDFMDLector` / `AppUserModelID="TRODAI.PDFMDLector"`
- `PrivilegesRequired=lowest` with `PrivilegesRequiredOverridesAllowed=dialog` (installs cleanly into `%LOCALAPPDATA%\Programs\TRODAI\PDF-MD-Lector` without UAC admin elevation).
- Languages: Spanish (`es`), English (`en`), Brazilian Portuguese (`pt_br`), Portuguese (`pt`).
- Optional `HKCU` file associations (`TRODAI.PDFMDLector.PDF`, `TRODAI.PDFMDLector.MD` unchecked by default) with full cleanup on uninstall.
- Supports optional `SignTool` signing when compiled with `/DMySignTool`.
