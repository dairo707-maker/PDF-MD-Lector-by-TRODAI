# Code of Conduct

## Our Pledge

Contributors and maintainers of **PDF/MD Lector by TRODAI** pledge to keep participation welcoming, respectful, technical, and harassment-free for everyone regardless of background or experience level.

## Expected Behavior

- Communicate constructively and focus feedback on code correctness, security, and maintainability.
- Respect licensing, API provider Terms of Service, user privacy, and open-source attribution.
- Report suspected security issues privately following [SECURITY.md](SECURITY.md).

## Unacceptable Behavior

- Harassment, personal attacks, derogatory comments, or publishing others' private information.
- Submitting obfuscated code, telemetry trackers, credential harvesters, or path_guard/sandbox bypasses.

## Enforcement

Maintainers may edit, reject, or close offending issues/PRs and block repeat offenders. Contact **Dairo Trocha (TRODAI)** via repository advisories or maintainer channels.
